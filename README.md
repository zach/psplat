# psplat

Perceptual, budget-scalable Gaussian splats. Takes a trained 3D Gaussian Splat
scene, runs a one-time perceptual analysis, and emits a progressively
decodable, perceptually ordered splat file that any engine can truncate at an
arbitrary budget.

Status: planning. Nothing to install yet.

- `docs/handoff.md` — the project brief (source of truth for scope and decisions)
- `docs/plan.md` — the work breakdown, risks, and open decisions
- `docs/lab-notebook.md` — append-only log of what ran and what came out
